# Project Structure

```
customer-email-triage-agent/
├── README.md
├── LICENSE
├── .gitignore
├── docs/
│   ├── Problem-Statement.md
│   ├── Architecture.md
│   ├── Setup-Guide.md
│   ├── Workflow-Explanation.md
│   ├── Project-Structure.md
│   ├── FAQ.md
│   └── SECURITY.md
├── assets/
│   └── (diagrams, exported visuals — added by project owner)
├── screenshots/
│   └── (Make.com scenario screenshots — added by project owner)
└── examples/
    ├── sample-input-email.md
    └── sample-output-acknowledgment.md
```

## Folder Purposes

| Path | Purpose |
|---|---|
| `README.md` | Project overview, quick-start, and navigation hub for the whole repo |
| `LICENSE` | Legal terms for reuse/modification of this project |
| `.gitignore` | Prevents secrets, credentials, and local artifacts from being committed |
| `docs/` | All written documentation — problem context, architecture, setup, workflow |
| `assets/` | Visual resources (diagrams, exported images) — populated separately, not code |
| `screenshots/` | Scenario/module screenshots from Make.com — populated separately |
| `examples/` | Realistic sample input and output so a reader can see the system in action without running it |
